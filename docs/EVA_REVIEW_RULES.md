# Eva: правила интерфейса для проверки заказчиком

Изменения применены только к Grigoriy-eva. Перенос в шаблон салона требует отдельного одобрения результата на Pages.

- Название услуги переносится только целыми словами, включая уточнения в скобках. Все части сохраняют шрифт заголовка.
- Тарифы находятся под названием: одна строка на вариант, подпись слева, стоимость по общему правому краю. Основная стоимость/диапазон остаётся справа.
- Дубли тарифов удаляются из отображаемого описания, исходный прайс не меняется.
- Без тарифов: описание до двух фактических строк видно целиком без кнопки. Более длинное раскрывается через «Подробнее». С тарифами: дополнительное описание всегда свёрнуто. Если описания нет, кнопки нет.
- Диапазон «от X до Y» выводится через тире; одиночное «от X» сохраняется.
- В портфолио на главной ровно 7 фотографий. Полная галерея сохраняет все фотографии.
- Галерея обновляет сетку, сохраняя полосу категорий и её прокрутку.
- Портреты мастеров в списке и профиле: квадратный контейнер, круглая обрезка, object-fit: cover; изображение не выходит за границы круга.
- Команда на ПК: страницы по 4 мастера, сетка 2 × 2.
- Профиль: портрет, имя, специализация; О мастере → Услуги → Портфолио → Отзывы. Первые 6 услуг и раскрытие остальных; закреплённая навигация и кнопка записи.
- Работы подбираются по специальности и обозначаются как работы студии. Персональные отзывы используются только при явной связи с мастером в данных.
- На ПК нет категории «Все». Запись с услуги или профиля открывает выбор способа связи.
